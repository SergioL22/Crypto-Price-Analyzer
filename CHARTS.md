# Exploring price history

The chart starts as a simple line using the history already loaded by View analysis.
Drag horizontally to pan, scroll or pinch to zoom, and hover or tap to inspect a date and price. Keyboard users can focus the chart and use arrow keys to select dates, plus/minus to zoom, and Home/End to jump to the visible endpoints. The date slider provides another way to inspect observations.

Show selects a recent calendar window. After a gesture it displays Custom view. Latest moves the current window to the newest data; Reset view restores the entire loaded history. Fullscreen expands the chart within the app; Escape or Exit fullscreen returns to the page.

Stocks and ETFs offer daily candlesticks only when genuine, valid open/high/low/close bars match the history. Crypto retains its line chart because its daily samples do not contain OHLC. Advanced tools optionally display moving averages, Bollinger Bands, daily share volume when available, and exact values. Indicators use the original history, not recalculations on the zoomed portion. Missing observations are never interpolated.

Chart navigation makes no additional provider or AI requests. This upgrade does not add live intraday candles, drawing tools, or price predictions.
