Prepared October 20, 2026. Not sent. No subscription or account changes made.

First recipient: Twelve Data support, via its official support/contact form. Existing integration makes this the simplest route if a free public noncommercial pilot is possible. If declined, send the same request to Marketstack sales; its free tier's noncommercial label alone does not establish redistribution permission.

Subject: Permission for a small free public US stock/ETF research pilot

Hello,

I run a small noncommercial stock/ETF research website at https://research-desk-demo-tupe.onrender.com/. My budget for market data is $0. The public site currently displays official TradingView widgets; it does not redistribute your API data. I would like to understand whether you can authorize a limited free pilot using your end-of-day US stock and ETF data.

The proposed features are historical price charts, indicators, browser-local watchlists, manually checked price/indicator alerts, historical comparisons and a hypothetical investment calculator. There is no trade execution. We can restrict the initial symbol list, history depth, refresh frequency and visitor volume to fit an approved allowance.

Can you confirm in writing whether a free arrangement is available and specify:

1. The permitted symbols, exchanges, historical OHLC/volume coverage, split adjustments and delay.
2. Permission for anonymous public display and browser JSON responses used to calculate and render the tools.
3. Permission to display derived indicators, comparison returns and hypothetical investment results.
4. Required attribution, caching duration, retention and any export restrictions.
5. Per-endpoint credit weights, rate/day/month limits, hard spending caps and any exchange/add-on fees. The pilot cannot incur charges.
6. Any application, eligibility, expiry or renewal requirements.

Model training, immutable research snapshots and prediction outputs would require separate explicit permission and are outside this proposed public pilot.

Please do not activate paid services. If no free arrangement covers this use, please confirm that so we can retain the widget-only public version.

Thank you.

## Decision gate

Keep public provider API access disabled until actual written rights and the exact no-charge allowance are established. A reply offering API access or a commercial-use badge without covering display, JSON and derived outputs is not enough. Translate any permitted retention and usage limits into implementation checks before adding real-price calculations.
